# Generated feature illustrations

These images are generated feature-area illustrations, not screenshots of a real Slack workspace or Redmine deployment. All names, issues, channels, and configuration values are fictional. English and Japanese documentation share the same English-language assets. Surrounding application navigation is deliberately omitted to avoid suggesting unsupported screens.

Created with the built-in `image_gen` tool. The complete shared prompt, per-image instructions, and README section mapping are saved in [prompts.json](prompts.json). WEBP assets are encoded from the generated PNG originals without changing their content.

Configuration examples show YAML snippets, not a configuration GUI. The repository's YAML example and documentation define the supported settings. Slack controls its native layouts and may render them differently by client and version. These images illustrate supported content and controls, not pixel-exact client rendering.

The source review for the corrected illustrations is recorded in [implementation-review.md](implementation-review.md).
